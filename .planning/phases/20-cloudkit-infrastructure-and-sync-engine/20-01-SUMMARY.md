## Decisions Made
- **xcodegen `sdk` instead of `framework`:** The plan specified `framework: CloudKit.framework` but xcodegen treated that as a local file reference (sourceTree = "<group>"). - **cloudKitDatabase: .private:** Used `.private("iCloud.app.pastel.Pastel")` as specified in the plan, giving explicit control over the container identifier rather than relying on `.automatic` inference.
