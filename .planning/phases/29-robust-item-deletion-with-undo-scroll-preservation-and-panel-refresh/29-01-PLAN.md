  <action>
Create `DeletionManager.swift` in `Pastel/Services/` as an `@MainActor @Observable final class`.

**Properties:**
- `private(set) var pendingDeletion: SoftDeleteEntry?` — the single undo buffer
- `var softDeletedIDs: Set<PersistentIdentifier>` — computed from pendingDeletion, returns set with the pending item's ID or empty set
- `private var cleanupWorkItem: DispatchWorkItem?` — cancellable deferred image cleanup
- `private let trashSound: NSSound?` — loaded once from `/System/Library/Components/CoreAudio.component/Contents/SharedSupport/SystemSounds/finder/move to trash.aif` using `byReference: true`

**SoftDeleteEntry struct** (nested):
- `itemID: PersistentIdentifier`
- `imagePath: String?`
- `thumbnailPath: String?`
- `urlFaviconPath: String?`
- `urlPreviewImagePath: String?`

**Methods:**

`func softDelete(_ item: ClipboardItem, in modelContext: ModelContext)`:
1. If there is an existing `pendingDeletion`, commit it first via `commitPendingDeletion(in: modelContext)`.
2. Store new `SoftDeleteEntry` with item's `persistentModelID` and image paths.
3. Play `trashSound?.play()`.
4. Schedule deferred image cleanup via `scheduleImageCleanup()`.

`func undo(in modelContext: ModelContext)`:
1. Guard `pendingDeletion` exists, else return.
2. Cancel `cleanupWorkItem`.
3. Fetch the item via `modelContext.model(for: pendingDeletion!.itemID) as? ClipboardItem`. If found, set `item.timestamp = .now` and call `saveWithLogging(modelContext, operation: "undo soft-delete")`. This ensures the restored item sorts to position #1 (top of list) per the locked decision, regardless of when it was originally copied.
4. Set `pendingDeletion = nil` (this makes `softDeletedIDs` empty, re-showing the item).

`func commitPendingDeletion(in modelContext: ModelContext)`:
1. Guard `pendingDeletion` exists.
2. Cancel any pending `cleanupWorkItem` (images will be deleted with the item now).
3. Fetch the item via `modelContext.model(for: entry.itemID) as? ClipboardItem`.
4. If found, call `deleteClipboardItemWithCleanup(item, from: modelContext)` then `saveWithLogging(modelContext, operation: "commit soft-delete")`.
5. Set `pendingDeletion = nil`.

`private func scheduleImageCleanup()`:
1. Cancel previous `cleanupWorkItem`.
2. Create new `DispatchWorkItem` that deletes image files using `ImageStorageService.shared.deleteImage(imagePath:thumbnailPath:)` for both clipboard images and URL metadata images.
3. Dispatch after 10 seconds delay on main queue.

**Important:** Import SwiftData, AppKit (for NSSound), and reference the free functions `deleteClipboardItemWithCleanup` and `saveWithLogging` from SwiftDataHelpers.swift. Follow the project's existing `@MainActor @Observable` service pattern (like ClipboardMonitor, SyncMonitor).
