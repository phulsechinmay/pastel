  <action>
1. **Create `Pastel/Services/ItemLifecycleService.swift`** — A @MainActor final class combining both services:

   Properties:
   - `private let modelContext: ModelContext`
   - `private var retentionTimer: Timer?`
   - `private var pendingExpirations: [PersistentIdentifier: DispatchWorkItem] = [:]`
   - `private static let logger = Logger(subsystem: ..., category: "ItemLifecycleService")`

   Init: `init(modelContext: ModelContext)` — stores modelContext.

   Retention methods (from RetentionService):
   - `func startPeriodicPurge()` — calls purgeExpiredItems() immediately, then schedules hourly Timer. Exact same logic as RetentionService.startPeriodicPurge().
   - `func purgeExpiredItems()` — reads `historyRetention` from UserDefaults. If 0 (Forever), return. Otherwise fetch items older than cutoff, loop calling `deleteClipboardItemWithCleanup(item, from: modelContext)` for each, then `try modelContext.save()`. Rollback on error. (Uses helper from Plan 01.)

   Expiration methods (from ExpirationService):
   - `func scheduleExpiration(for item: ClipboardItem)` — identical logic: guard isConcealed, capture itemID, create DispatchWorkItem calling performExpiration, schedule 60s from now.
   - `func cancelExpiration(for itemID: PersistentIdentifier)` — identical to ExpirationService.
   - `func expireOverdueItems()` — fetch concealed items with expiresAt, delete expired ones via `deleteClipboardItemWithCleanup`, save. (Uses helper from Plan 01.)
   - `private func performExpiration(itemID: PersistentIdentifier)` — remove from pending, fetch item by ID, guard exists, call `deleteClipboardItemWithCleanup(item, from: modelContext)`, save. Note: no longer needs imagePath/thumbnailPath parameters since the helper reads directly from the item. Simplified signature.

   Stop method:
   - `func stop()` — invalidate retentionTimer, cancel all pendingExpirations, removeAll.

2. **Rewire AppState.swift:**
   - Change `var retentionService: RetentionService?` to `var lifecycleService: ItemLifecycleService?`
   - In `setup()` method: Create `ItemLifecycleService(modelContext: modelContext)` instead of `RetentionService`. Call `lifecycleService.startPeriodicPurge()`. Store as `self.lifecycleService`.
   - Pass `lifecycleService` to ClipboardMonitor init (see below).
   - If there is a `stop()` or cleanup path that calls `retentionService?.stop()`, update to `lifecycleService?.stop()`.

3. **Rewire ClipboardMonitor.swift:**
   - Change `private let expirationService: ExpirationService` to accept `ItemLifecycleService` instead. Update the property name to `lifecycleService` (or keep `expirationService` renamed — use `lifecycleService` for clarity).
   - Update init: Remove internal creation of ExpirationService (`self.expirationService = ExpirationService(modelContext: modelContext)`). Instead accept `lifecycleService: ItemLifecycleService` as an init parameter.
   - Update all 3 call sites in ClipboardMonitor that reference expirationService:
     - `expirationService.expireOverdueItems()` -> `lifecycleService.expireOverdueItems()`
     - `expirationService.scheduleExpiration(for: item)` (2 locations) -> `lifecycleService.scheduleExpiration(for: item)`
   - Update AppState where ClipboardMonitor is created to pass the lifecycleService.

4. **Delete ExpirationService.swift and RetentionService.swift** from disk (rm the files).

5. **Run `xcodegen generate`** to regenerate the Xcode project with the new file and without the deleted files. Verify the Pastel scheme still exists afterward (CRITICAL per MEMORY.md).
