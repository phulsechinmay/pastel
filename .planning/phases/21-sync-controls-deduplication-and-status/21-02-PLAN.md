**1. Create Pastel/Views/Settings/SyncSettingsView.swift (~180 lines)**

A SwiftUI view for the iCloud Sync settings tab. Follow the visual patterns from GeneralSettingsView (Form with sections, consistent spacing).

```swift
import SwiftUI
import SystemConfiguration
```

Properties:
- `@Environment(SyncMonitor.self) private var syncMonitor: SyncMonitor?` -- optional because nil when sync disabled (Plan 01 only creates SyncMonitor when enabled)
- `@AppStorage("iCloudSyncEnabled") private var iCloudSyncEnabled = false`
- `@State private var showingRestartAlert = false`
- `@State private var showingHelpPopover = false`

**Sync Toggle Section:**
- `Toggle("iCloud Sync", isOn: $iCloudSyncEnabled)` with `.onChange(of: iCloudSyncEnabled)` that sets `showingRestartAlert = true` on EVERY change (per CONTEXT.md: "even if flipped back to original state").
- Below the toggle, a `Text` description in `.font(.caption)` and `.foregroundStyle(.secondary)`: "Sync clipboard history across your Macs via iCloud. Text, URLs, code snippets, color values, and labels are synced. Images, files, and passwords are not synced."

**iCloud Account Section (below toggle):**
- Show iCloud account status. If `syncMonitor` exists and has `iCloudAccountName`, show "iCloud Account: [name]". If `syncMonitor` exists but `iCloudAccountName` is nil, show "iCloud Account: Available" with a green checkmark. If `syncMonitor?.state == .accountUnavailable`, show "iCloud Account: Not Signed In" with a warning icon. If `syncMonitor` is nil (sync disabled), show "iCloud Account: Enable sync to check" in secondary text.
- Use `HStack` with `Image(systemName:)` and `Text`.

**Sync Status Section (only when sync enabled):**
- Only show this section when `iCloudSyncEnabled` is true.
- Follow CONTEXT.md "silence = success" rule:
  - `.synced` state: Show a very minimal green dot + "Synced" text. The "silence = success" means no menu bar / panel changes -- in the Settings tab itself, showing the current state is expected since the user explicitly navigated there.
  - `.syncing` state: pulsing orange/blue dot + "Syncing..." text. Use a simple opacity animation for the pulsing effect (withAnimation(.easeInOut(duration: 0.8).repeatForever(autoreverses: true))).
  - `.error(let message)` state: red dot + error message text
  - `.accountUnavailable` state: red dot + "iCloud account not available"
  - `.disabled` state: gray dot + "Sync disabled"
- Status dot: Use `Circle().fill(color).frame(width: 8, height: 8)` where color is green/orange/red/gray based on state.
- "?" help button: `Button` with `Image(systemName: "questionmark.circle")` styled as `.buttonStyle(.plain)` that toggles `showingHelpPopover`. Place it in the section header or next to the status label.

**Help Popover:**
- `.popover(isPresented: $showingHelpPopover)` attached to the "?" button.
- Content (lightweight, NOT a full sheet -- per CONTEXT.md "similar to macOS system preference info popovers"):
  - "What syncs" section: Text, URLs, code snippets, color values, labels
  - "What doesn't sync" section: Images, files, passwords (concealed items)
  - "This device" section: Show device name from `SCDynamicStoreCopyComputerName(nil, nil) as String? ?? ProcessInfo.processInfo.hostName`
- Use `VStack(alignment: .leading, spacing: 12)` with `.padding()` and `.frame(width: 260)`.

**Restart Alert:**
- `.alert("Restart Required", isPresented: $showingRestartAlert)` with two buttons:
  - `Button("Restart Now") { AppRelaunchService.relaunch() }`
  - `Button("Later", role: .cancel) { }` -- does nothing, the UserDefaults change is already persisted via @AppStorage binding
- Message: `Text("Pastel needs to restart to apply the sync change. Your clipboard history will be preserved.")`
- Note: The @AppStorage binding writes UserDefaults BEFORE the alert appears, so "Later" correctly preserves the toggle state. The restart just applies the ModelContainer change.

**Layout:**
- Use `ScrollView` > `VStack(alignment: .leading, spacing: 24)` > sections with section headers.
- Section headers: `Text("SECTION NAME").font(.caption).foregroundStyle(.secondary).textCase(.uppercase)`
- Match the visual density of GeneralSettingsView.
- Apply `.fontDesign(.rounded)` to match the app-wide font.
- Padding: `.padding(24)` on the outer VStack.

**2. Update Pastel/Views/Settings/SettingsView.swift**

Add the iCloud Sync tab to the existing `SettingsTab` enum:

In the `SettingsTab` enum, add a new case AFTER `.history`:
```swift
case iCloudSync
```

Add to `iconName` switch:
```swift
case .iCloudSync: return "icloud"
```

Add to `displayName` switch:
```swift
case .iCloudSync: return "iCloud Sync"
```

Add to the `switch selectedTab` in the body's content area:
```swift
case .iCloudSync:
    SyncSettingsView()
```

Since `SettingsTab` uses `CaseIterable` and `ForEach(SettingsTab.allCases)`, adding the enum case automatically includes it in the tab bar. The existing frame constraints already give `.history` expanded sizing and all other tabs fixed sizing -- no changes needed there.
