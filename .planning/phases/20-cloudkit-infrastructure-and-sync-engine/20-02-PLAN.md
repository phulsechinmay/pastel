  <name>Task 1: Add remote-item filtering predicates to panel and history views</name>
  <files>Pastel/Views/Panel/FilteredCardListView.swift, Pastel/Views/Settings/HistoryGridView.swift</files>
  <action>
Update the @Query predicate construction in both `FilteredCardListView.init()` and `HistoryGridView.init()` to exclude items that should not be displayed from remote devices.

**Filtering logic (same for both views):**

The base predicate must exclude:
1. **Concealed items from ANY device** -- `isConcealed == true` items should be filtered from panel/history queries entirely. On the local device, concealed items are shown briefly then auto-expire (ExpirationService handles this). But in the synced world, a concealed item from another device should NEVER appear. The simplest approach: filter `isConcealed == true` from all query results. The local device's ExpirationService still manages the 60s lifecycle, but the panel won't show concealed items at all (they were never meant to be browseable -- only the most recent paste matters for concealed items, and that is handled by the paste-back flow, not the panel).

2. **Image/file items from remote devices** -- Items where `contentType == "image"` or `contentType == "file"` AND `originDeviceID != DeviceIdentifier.current` have no displayable content (image files are local). Filter these out. Local image/file items display normally.

**Implementation approach:**

In both `FilteredCardListView.init()` and `HistoryGridView.init()`, modify the predicate construction. The current pattern is:

```swift
// Current (no search):
predicate = #Predicate<ClipboardItem> { _ in true }

// Current (with search):
predicate = #Predicate<ClipboardItem> { item in
    item.textContent?.localizedStandardContains(search) == true ||
    item.sourceAppName?.localizedStandardContains(search) == true ||
    item.title?.localizedStandardContains(search) == true
}
```

The updated pattern captures the local device ID and adds exclusion conditions:

```swift
let localDeviceID = DeviceIdentifier.current
let imageType = ContentType.image.rawValue
let fileType = ContentType.file.rawValue

// Build the base exclusion predicate that is ANDed with search:
// Exclude: isConcealed == true (from any device -- panel never shows concealed items)
// Exclude: remote image/file items (no displayable content on receiving device)
if !searchText.isEmpty {
    let search = searchText
    predicate = #Predicate<ClipboardItem> { item in
        item.isConcealed == false &&
        (item.originDeviceID == localDeviceID ||
         (item.contentType != imageType && item.contentType != fileType)) &&
        (item.textContent?.localizedStandardContains(search) == true ||
         item.sourceAppName?.localizedStandardContains(search) == true ||
         item.title?.localizedStandardContains(search) == true)
    }
} else {
    predicate = #Predicate<ClipboardItem> { item in
        item.isConcealed == false &&
        (item.originDeviceID == localDeviceID ||
         (item.contentType != imageType && item.contentType != fileType))
    }
}
```

**Key considerations:**
- `item.isConcealed == false` filters ALL concealed items. This is safe because concealed items were never browseable in the panel -- they only matter for the immediate paste-back (which reads from NSPasteboard, not SwiftData).
- The `originDeviceID == localDeviceID` check allows ALL local items through (including local images). Remote items are only allowed if they are NOT image/file types.
- `originDeviceID` may be empty string for old items (pre-v1.5). Empty string `!= DeviceIdentifier.current` so they would be treated as "remote" -- but old items are all local and won't have image/file contentType from another device (they predate sync). However, to be safe, also allow items with empty `originDeviceID` through: `item.originDeviceID == "" || item.originDeviceID == localDeviceID || (contentType checks)`.

**Revised predicate with empty-string safety:**

```swift
let localDeviceID = DeviceIdentifier.current
let imageType = ContentType.image.rawValue
let fileType = ContentType.file.rawValue

// An item is "local" if originDeviceID matches this device OR is empty (pre-sync legacy items)
// A remote item is allowed only if it is NOT image/file type
// Concealed items are always excluded (passwords should never appear in browseable history)

if !searchText.isEmpty {
    let search = searchText
    predicate = #Predicate<ClipboardItem> { item in
        item.isConcealed == false &&
        (item.originDeviceID == localDeviceID ||
         item.originDeviceID == "" ||
         (item.contentType != imageType && item.contentType != fileType)) &&
        (item.textContent?.localizedStandardContains(search) == true ||
         item.sourceAppName?.localizedStandardContains(search) == true ||
         item.title?.localizedStandardContains(search) == true)
    }
} else {
    predicate = #Predicate<ClipboardItem> { item in
        item.isConcealed == false &&
        (item.originDeviceID == localDeviceID ||
         item.originDeviceID == "" ||
         (item.contentType != imageType && item.contentType != fileType))
    }
}
```

Apply this IDENTICAL predicate logic to BOTH:
1. `FilteredCardListView.init()` -- panel view
2. `HistoryGridView.init()` -- history browser view

**IMPORTANT SwiftData #Predicate pitfall:** Do NOT use optional chaining with `== true` on non-optional Bool properties. `isConcealed` is a non-optional `Bool` with default `false`, so `item.isConcealed == false` is correct. `originDeviceID` is a non-optional `String` with default `""`, so direct comparison works. `contentType` is a non-optional `String` with default, so direct comparison works.
