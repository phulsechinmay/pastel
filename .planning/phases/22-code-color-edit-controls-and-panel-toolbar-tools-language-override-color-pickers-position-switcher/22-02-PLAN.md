  **New file: Pastel/Services/ColorToolController.swift**

  Create a `@MainActor final class ColorToolController` with a `static let shared` singleton. It manages `NSColorPanel.shared` for standalone color picking:

  1. `func showColorPicker()`:
     - Access `NSColorPanel.shared`
     - Set `panel.setTarget(self)` and `panel.setAction(#selector(colorDidChange(_:)))`
     - Set `panel.isContinuous = true` (updates on every drag)
     - Set `panel.level = .floating` (appears above the sliding panel which is at `.statusBar` level -- actually `.floating` may be below `.statusBar`. Check research: research says set to `.floating` or `.statusBar`. Use `NSWindow.Level(rawValue: NSWindow.Level.statusBar.rawValue + 1)` to ensure it's ABOVE the panel. Or use `.screenSaver` level. Actually safer: just use `.floating` and note that the panel may need to dismiss first. The simplest approach: set `panel.level = .statusBar` so it's at the same level as the sliding panel.)
     - Call `panel.orderFront(nil)` (not `makeKeyAndOrderFront` to avoid stealing focus from the sliding panel prematurely)
     - Register for `NSWindow.willCloseNotification` on the color panel to clear target/action when it closes (prevents conflicts with SwiftUI ColorPicker in edit modal)

  2. `@objc private func colorDidChange(_ sender: NSColorPanel)`:
     - Get `sender.color`
     - Convert to sRGB: `guard let rgb = sender.color.usingColorSpace(.sRGB) else { return }`
     - Format hex: `String(format: "#%02X%02X%02X", Int(rgb.redComponent * 255), Int(rgb.greenComponent * 255), Int(rgb.blueComponent * 255))`
     - Copy to clipboard: `NSPasteboard.general.clearContents()` then `NSPasteboard.general.setString(hex, forType: .string)`
     - IMPORTANT: The ClipboardMonitor will pick this up and create a color item automatically (since ColorDetectionService will detect the hex). This is desired behavior -- the user picks a color, it goes to clipboard, and appears in history as a color card.

  3. `private func cleanupTarget()`:
     - Called from willClose notification
     - `NSColorPanel.shared.setTarget(nil)`
     - `NSColorPanel.shared.setAction(nil)`
     - Remove the notification observer

  Make ColorToolController inherit from NSObject so it can be an @objc target.
