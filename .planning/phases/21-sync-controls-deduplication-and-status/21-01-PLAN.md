**1. Pastel/Services/SyncMonitor.swift (~70 lines)**

An `@MainActor @Observable` class that exposes sync state for the UI:

```swift
import CloudKit
import CoreData
import OSLog
```

- Define `SyncState` enum with cases: `.disabled`, `.synced`, `.syncing`, `.error(String)`, `.accountUnavailable`
- Stored property `var state: SyncState = .disabled`
- Stored property `var iCloudAccountName: String?` (for display in Settings)
- Private properties for `eventObserver: Any?` and `accountObserver: Any?`
- Logger with subsystem `"app.pastel.Pastel"`, category `"SyncMonitor"`

`func startMonitoring()`:
- Subscribe to `NSPersistentCloudKitContainer.eventChangedNotification` on `NotificationCenter.default` (queue: `.main`). In the handler, extract the `Event` from `notification.userInfo?[NSPersistentCloudKitContainer.eventNotificationUserInfoKey] as? NSPersistentCloudKitContainer.Event`. If `event.endDate == nil`, set state to `.syncing`. If `event.error != nil`, set state to `.error(error.localizedDescription)`. Otherwise set state to `.synced`.
- IMPORTANT: Debounce state transitions to avoid flickering. When setting `.synced`, use a 1-second delay (DispatchWorkItem that sets `.synced` only if no new `.syncing` event arrived). Store the work item privately and cancel it when a new syncing event starts.
- Subscribe to `.CKAccountChanged` on `NotificationCenter.default` (queue: `.main`). In handler, call `Task { @MainActor in await self?.checkAccountStatus() }`.
- Call `Task { await checkAccountStatus() }` for initial check.

`private func checkAccountStatus() async`:
- Use `CKContainer(identifier: "iCloud.app.pastel.Pastel")`.
- Call `try? await container.accountStatus()`. If not `.available`, set `state = .accountUnavailable`, set `iCloudAccountName = nil`, return.
- Try to get user name (without prompting for permission): `try? await container.fetchUserRecordID()` then `try? await container.discoverUserIdentity(withUserRecordID:)`. If successful, format with `PersonNameComponentsFormatter` and store in `iCloudAccountName`. If not available, leave `iCloudAccountName = nil` (UI will show "iCloud: Available" fallback).

`func stopMonitoring()`:
- Remove both observers, set `state = .disabled`.

**2. Pastel/Services/DeduplicationService.swift (~100 lines)**

An `@MainActor` class for merging duplicate items from CloudKit:

```swift
import SwiftData
import OSLog
```

- Private properties: `observer: Any?`, `modelContext: ModelContext`, `debounceTask: Task<Void, Never>?`
- Logger with subsystem `"app.pastel.Pastel"`, category `"Dedup"`
- Init takes `ModelContext`

`func startMonitoring()`:
- Subscribe to `.NSPersistentStoreRemoteChange` on `NotificationCenter.default` (object: nil, queue: nil). In the handler, debounce by cancelling any existing `debounceTask` and creating a new `Task { @MainActor in try? await Task.sleep(for: .seconds(3)); self?.deduplicateItems() }`. The 3-second debounce handles rapid batch imports.

`private func deduplicateItems()`:
- Fetch ALL items with a `FetchDescriptor<ClipboardItem>(sortBy: [SortDescriptor(\.timestamp, order: .forward)])`.
- Group by `contentHash` into `[String: [ClipboardItem]]`, filtering out empty hashes.
- For each group with count > 1:
  - Determine the "keeper": prefer the item where `originDeviceID == DeviceIdentifier.current` (local device wins per CONTEXT.md decision). If no local item exists (both from other devices), keep the one with the earliest timestamp.
  - Merge labels from all duplicates onto the keeper using union: collect all `safeLabels` from all items in the group, deduplicate by label identity (PersistentIdentifier), assign merged set to `keeper.safeLabels`.
  - Log the merge: `logger.info("Dedup: merging \(group.count - 1) duplicate(s) of hash \(hash.prefix(8))...")`
  - Save the merge with `saveWithLogging(modelContext, operation: "dedup-label-merge")`.
  - THEN delete the non-keeper items in a SEPARATE loop (not same save -- avoids CloudKit merge conflicts per research pitfall 2).
  - Save deletions with `saveWithLogging(modelContext, operation: "dedup-delete-duplicates")`.
- Log summary: `logger.info("Dedup pass complete: \(mergedCount) group(s) merged")`

`func stopMonitoring()`:
- Remove observer, cancel debounceTask.

**3. Pastel/Utilities/AppRelaunchService.swift (~15 lines)**

A simple enum with a static function:

```swift
import AppKit

enum AppRelaunchService {
    static func relaunch() {
        let bundlePath = Bundle.main.bundlePath
        // Ensure UserDefaults is flushed before termination
        UserDefaults.standard.synchronize()
        let task = Process()
        task.launchPath = "/bin/sh"
        task.arguments = ["-c", "sleep 1; open \"\(bundlePath)\""]
        try? task.run()
        NSApp.terminate(nil)
    }
}
```

Per CONTEXT.md decision: spawn `/bin/sh -c "sleep 1; open <bundlePath>"` then `NSApp.terminate(nil)`. Call `UserDefaults.standard.synchronize()` before termination to prevent restart loop (research pitfall 4).
